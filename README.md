<h1>Portfolio 2026 - Ewan Baverel</h1>
<p>Personal portfolio showcasing front-end engineering and digital design. Built with React & TS.</p>
<h3>Context</h3>
<p>This project has been developed to showcase my skills as part of my application for the French university course BUT MMI, a three-year degree focused on multimedia and IT professions.</p>
<h3>Used stacks</h3>
<p>This project was built using :</p>
<ul>
  <li>React and TypeScript to deliver a powerful website focused on a dynamic user experience with minimal friction.</li>
  <li>Framer Motion to bring it to life with smoother, more natural animations than CSS-based alternatives.</li>
  <li>React-i18next to easily translate this project into every language I speak.</li>
</ul>
<h3>Visual Architecture</h3>
<p>To develop this project, I started by designing a complete wireframe to visualise how I'd organise each section and piece of info, ensuring a user-friendly and responsive layout. From there, I chose a colour palette that enhances readability and guide user interactions :</p>
<ul>
  <li>Cornsilk as my primary colour, which provides a softer contrast than pure white to reduce visual fatigue</li>
  <li>Coffee Bean as the secondary colour to structure the interface and cleanly separate distinct sections.</li>
  <li>Harvest Orange as the accent colour that draws attention to key items and interactive elements thanks to its saturated colour.</li>
</ul>
<h3>Data architecture</h3>
<p>To ensure a smooth navigation without page reloads and the ability to easily add future projects, I centralized my project data in a single file. I mapped them to ensure consistent display across all pages generated automatically with React Router. To make this more robust, I used conditional rendering on data that might not be used.</p>
<h3>Local installation</h3>
<p>Here's how to get it running on your machine:</p>
<ul>
  <li>1. Clone this project into your code editor using <code>git clone https://github.com/wannnwannn/Portfolio-Baverel-Ewan.git</code>.</li>
  <li>2. Run <code>npm install</code> to install the dependencies.</li>
  <li>3. Finally, run <code>npm run dev</code> to start the local development server.</li>
</ul>
